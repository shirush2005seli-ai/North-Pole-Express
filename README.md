# North Pole Express

Upload all extracted files to the root of your GitHub repository. For Vercel import the repository; framework Other, no build command, output directory root (as set in vercel.json).

Includes the Christmas village, snowflakes, 30 wishes, letter writer, simplified adults page, and returning-families page.

Initial package: $13.99 for a parent email copy of the child's letter, plus a mailed certificate and personalized Santa letter. Subsequent personalized mailed replies: $7 each, no subscription.

PayPal, automatic email, secure order storage, original-order verification, and private mailing-address release are not connected. Checkout remains disabled. No private mailing address is in the site source. Do not add it to public HTML, JavaScript, GitHub, or downloadable PDFs; it must be released by the server only after both payments are verified. Paid families can keep the address after receiving it, so each later response still needs its own paid order/reference.

Private business configuration and printable fulfillment templates are intentionally excluded from this public website package.
